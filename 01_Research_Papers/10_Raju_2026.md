# Raju et al. (2026)

## Paper Title

Secure-by-Design Cloud Architectures: Integrating Machine Learning with Zero Trust Security Models

## Authors

Raju et al.

## Year

2026

## Research Problem

The study investigates the integration of machine learning and Zero Trust security principles into cloud architectures.

## Method / Technique

The approach combines machine-learning-based threat detection with Zero Trust security concepts and cloud telemetry.

## Dataset / Tools

- Cloud security telemetry
- Machine Learning
- Zero Trust security model
- Cloud architecture

## Main Findings

The study demonstrates the potential of combining machine learning with Zero Trust principles to improve security monitoring in cloud environments.

## Limitation

The study is mainly conceptual and has limited extensive real-world validation for Federated Learning poisoning attacks.

## Relevance to Proposed Research

This study provides supporting context for implementing machine-learning-based security monitoring in cloud environments. It helps connect the proposed detection module with the cloud-based setting of the research.
