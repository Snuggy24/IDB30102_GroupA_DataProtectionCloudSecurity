## Overall Observation

The reviewed studies show that client model updates, gradients, statistical information and model behaviour can be used as signals for identifying malicious or poisoned client behaviour.

However, many existing approaches focus on specific attack types, while non-IID client data can make benign updates naturally different from one another. Some methods also introduce additional processing requirements.

These findings support the proposed development of a machine-learning-based detection module that analyses client updates before aggregation in a cloud-based Federated Learning environment.
