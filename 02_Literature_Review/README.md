# Literature Review

This folder contains the literature review analysis and supporting materials for Chapter 2.

The materials compare existing approaches for detecting and defending against data poisoning attacks in Federated Learning.

## Contents

- Literature review comparison table
- Existing detection techniques comparison
- Research gap analysis
- Detection methods summary
- Datasets and evaluation metrics

The literature review supports the proposed research on detecting data poisoning attacks in cloud-based Federated Learning using a machine-learning-based detection module.
